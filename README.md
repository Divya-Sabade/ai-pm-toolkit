# AI PM Toolkit

Free, practical templates for product managers building with AI. Copy them, adapt them, use them at work.

Made by [Divya Sabade](https://www.linkedin.com/in/divyasabade/) alongside the free course **[AI Product Management Foundations](https://learning-hub.divya-sabade.workers.dev/courses/ai-pm-foundations/)** on Sticky Notes on AI.

## What's inside

| File | Use it when |
| --- | --- |
| [AI product brief](templates/ai-product-brief-template.md) | You're pitching or scoping an AI feature on one page |
| [Eval sheet template](templates/eval-sheet-template.csv) | You need to define "good" before you build (opens in Excel or Google Sheets) |
| [Eval sheet example: refund assistant](templates/eval-sheet-example-refund-assistant.csv) | You want to see a filled-in eval sheet |
| [One-page AI risk review](templates/risk-review-template.md) | You're checking what could go wrong before launch |
| [AI PM interview questions](interview-prep/ai-pm-interview-questions.md) | You're preparing for AI PM interviews |

## How to use

1. Click a file, then **Raw** (or the download icon) to copy it.
2. Fill it in with a real feature you own. The templates work best on real work, not hypotheticals.
3. Want the "why" behind each template? Each one maps to a lesson in the free course.

## Stay in the loop
